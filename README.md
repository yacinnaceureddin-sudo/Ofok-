# أفق OFOQ — إدارة المتاجر الإلكترونية

تطبيق عربي باتجاه RTL لإدارة متجر إلكتروني للشركات الصغيرة والمتوسطة، مبني بواجهة HTML/CSS/JavaScript وقابل للتغليف كتطبيق Android باستخدام Capacitor.

## الوظائف المتاحة محلياً
- إعداد بيانات المتجر: الاسم والوصف والنشاط وصاحب المتجر ورقم التواصل ومعرّف رابط محلي.
- إنشاء المنتجات وتعديلها وحذفها، مع السعر والتصنيف والمخزون ورابط الصورة.
- تسجيل الطلبات وربطها بالمنتجات والعملاء، وحساب الإجمالي وتحديث المخزون.
- تغيير حالات الطلبات: جديد، قيد المعالجة، قيد الشحن، مكتمل، ملغى.
- لوحة إحصائيات للمبيعات المكتملة والطلبات والمنتجات والعملاء.
- عرض سجل العملاء المستخرج من الطلبات.
- مساعد محتوى تسويقي محلي بقوالب جاهزة، دون ادعاء الاتصال بنموذج AI.
- حفظ البيانات في `localStorage`، مع تصدير واستيراد نسخة JSON.
- تصميم ليلي بألوان Bleu Gauloises واتجاه RTL.

## التشغيل والاختبار
```sh
npm ci
npm test
```

يمكن تشغيل الواجهة عبر خادم محلي:
```sh
python -m http.server 8000 --directory www
```
ثم افتح `http://localhost:8000`.

## بناء APK
المشروع يستخدم Capacitor 6. لتوليد ملفات Android ثم بناء APK عبر بيئة Android/ GitHub Actions، استخدم إعدادات Capacitor في `capacitor.config.json`. ملف الناتج من workflow الحالي هو Debug APK للتجربة.

## حدود النسخة الحالية
هذه نسخة أولية محلية وليست منصة تجارة إلكترونية منشورة. لا يوجد خادم خلفي أو حسابات آمنة متعددة المستخدمين أو مزامنة بين الأجهزة أو واجهة متجر عامة مستضافة أو دفع إلكتروني أو تكامل شحن. لا يمكن للعملاء الخارجيين إرسال طلبات إلى هذا التطبيق المحلي. يلزم Backend وقاعدة بيانات واستضافة وبوابة دفع وتكاملات مناسبة لتشغيل هذه الوظائف فعلياً.

البيانات تحفظ على الجهاز/المتصفح فقط؛ حذف بيانات التطبيق أو المتصفح قد يؤدي إلى فقدانها. استخدم التصدير الدوري للاحتفاظ بنسخة احتياطية. الصور تُسجل حالياً كرابط خارجي اختياري ولا تُرفع إلى خادم.
